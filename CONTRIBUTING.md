# Contributing to RateFortress

I built RateFortress to experiment with and benchmark different rate limiting algorithms in Python, moving from in-memory prototypes to distributed Redis setups. It includes algorithm implementations, FastAPI middleware, and a test suite.

If you want to contribute, open a pull request or an issue. I care mainly that existing tests pass, new algorithms or features have tests covering edge cases and concurrency, and the code stays simple and easy to follow.
